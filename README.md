# Fraternity Management System

A full-stack web application for managing fraternity membership, financial transactions, chapter records, and family relationships.

## Overview

This project helps fraternity leadership track:

- Active members and alumni
- Membership status and contact details
- Transactions and payments
- Family tree / chapter relationships
- Administrative workflows and reporting

## Tech Stack

- React frontend
- Express backend
- PostgreSQL database support
- Node.js server environment

## Project Structure

- `src/` - React application
- `public/` - static frontend assets
- `backend/` - server-side API and database logic
- `setup.sql` - SQL setup for database tables

## Getting Started

### Frontend

```bash
npm install
npm start
```

The app runs in development mode at http://localhost:3000.

### Backend

```bash
cd backend
npm install
npm start
```

## Available Scripts

### `npm start`
Runs the frontend app in development mode.

### `npm run build`
Builds the production-ready frontend bundle.

### `npm test`
Runs the React test suite.

## Notes

This project was originally bootstrapped with Create React App but has been customized for fraternity operations and management workflows.
